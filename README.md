# DASHBOARD-PMBOK

Cruscotto multi-utente per le commesse Climosfera, secondo PMBOK (8ª ed.) e Lean (Last Planner System, Kanban). Si usa da PC Windows e Mac; i dati stanno su un unico server aziendale.

**Stato:** ricerca verificata; [prototipo cliccabile](prototipo/index.html) con dati di esempio (anteprima privata: https://claude.ai/artifact/Hau6bbX46GViVFRhGNUykN). Codice dell'app non ancora iniziato.
